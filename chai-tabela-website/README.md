# CHAI TABELA Website

A responsive cafe and restaurant starter website with menu filters, a shopping basket and WhatsApp checkout.

## Files
- `index.html` — website structure
- `style.css` — premium responsive styling
- `script.js` — menu items, basket and WhatsApp ordering

## Before publishing
1. Open `script.js`.
2. Replace `91XXXXXXXXXX` with your WhatsApp number (country code + number, digits only).
3. Edit the sample menu names, descriptions and prices in `menuItems`.
4. Update the address, opening hours and phone number in `index.html`.
5. Add your Google Maps link to `CAFE_MAPS_LINK` in `script.js` and wire it to the directions link if desired.

## Publish free with GitHub Pages
1. Open your repository `asifmallade/asifchaitabela`.
2. Choose **Add file → Upload files**.
3. Upload the four files from this folder (not the ZIP itself).
4. Click **Commit changes**.
5. Open **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then Save.
8. Wait a few minutes. Your site should appear at:
   `https://asifmallade.github.io/asifchaitabela/`

This is a front-end starter. WhatsApp checkout sends the order to your cafe; it does not process online card/UPI payments. A secure admin dashboard and database would need a backend service.
